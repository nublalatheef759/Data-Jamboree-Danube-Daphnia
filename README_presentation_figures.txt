FOR PRESENTATION — KEY FIGURES
===============================

This folder contains the most important figures for the group presentation.
All other supporting evidence is in the WebGestalt_ORA and iDEP_GSEA folders.

RECOMMENDED SLIDES (3-minute section):

SLIDE 1: Methods overview
- "Per-site DESeq2 → human ortholog mapping → pathway enrichment (WebGestalt ORA + iDEP GSEA)"
- Mention: GO, KEGG, Reactome databases; FDR < 0.05; cross-species validation with Drosophila

SLIDE 2: Main enrichment result
- USE: D11_1x_human_GO bar chart (WebGestalt)
- Shows top enriched GO terms: steroid metabolism, oxidative stress, lipid metabolism, chemical stress
- This is the richest result (874 human genes, 35+ significant GO terms)

SLIDE 3: Cross-site comparison
- USE: pathway_comparison_table.xlsx (GO Comparison sheet)
- Key message: "Lipid metabolism is universal, but downstream sites show endocrine disruption while upstream sites show glycan/lysosomal stress"
- Different pollution profiles → different biological responses
